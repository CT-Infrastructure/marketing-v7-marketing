# Security boundary
Runtime/session outbound remains HOLD on construction, duplicate, reconciliation and restore.
A historical synthetic RECONCILED/OCCURRED receipt records CONFIRMED with its
provider object and retained reservation, per accepted F04. It grants no send
authority. NOT_OCCURRED records HOLD/null object/no reservation, retaining its
action tombstone. Neither outcome permits retry.
No enable switch, production transport, credentials discovery or network.
Only bounded opaque synthetic references are accepted for local action identity;
fixed error strings avoid echoing rejected input. This is not a general PII scanner.
F16 requires independent SMS permission and two current reviews, lifecycle and
asset rights, with no email/phone substitution. Caller authenticates snapshots.
The synthetic verifier matches original byte fixtures copied at configuration;
it makes no claim to implement a real provider signature scheme.
Callbacks bind action/account/provider/object and time and cannot create sends.
Single caller in-memory state has no durability/concurrency or authenticated
backup guarantee. Real restoration and revocation replay require native evidence.
Do not import a candidate as production qualification or deploy the mock.

The public assembler reads only local pinned Git blobs through argument arrays.
It never fetches, invokes hooks or executes source code. It checks closed lock
shapes, full commits, regular blob modes, paths, sizes and SHA256 before atomic
publication. A failed assembly removes its staging directory and leaves the
destination absent. Existing destinations and symlink/junction ancestors are
rejected. Caller must exclusively own the destination parent during assembly;
this is not a defense against a hostile concurrent filesystem owner. Public
source integration runs with read-only source, no network and no credentials.
