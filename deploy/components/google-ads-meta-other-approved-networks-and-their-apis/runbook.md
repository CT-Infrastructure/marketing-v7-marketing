This package performs no ads calls, spend, provider discovery, endpoint selection, installation, scheduling or native writes. F05 does not register CP139 in providers. F16 tracking and audience_export remain distinct; consent diagnostics never grant budget or dispatch authority. Every policy result and journal runtime/configuration is HOLD, even when eligibility is ELIGIBLE_OFFLINE. Historical F04 OCCURRED receipts correctly say CONFIRMED; that history is not a runtime enablement flag.

## Public inputs and startup

Use a clean public marketing clone and an already available local Git object store containing the three control commits in public-inputs.lock.json. No fetch is performed by this assembler. From the component directory, with an absolute destination in an exclusively owned parent, run `python3 -B assemble_inputs.py --control-repository /absolute/local/control.git --destination /absolute/component/inputs`. It validates exact20 paths/commits/regular modes/sizes/SHA256 and publishes atomically from same-parent staging. Inputs must be absent initially. The loader reads component-local inputs only, verifies all20 before imports and never uses private execution files or snapshot-level fallbacks. Neither generated inputs nor external implementations are committed. Never run hooks or source instructions from the object store.

Use Python >=3.12,<4. Accepted F04 validation requires jsonschema/referencing and their approved offline dependencies in the independently admitted verifier environment; missing dependencies are a blocker, not a reason to substitute a validator, skip tests silently, install from network or claim full coverage.

## Pure interfaces

`assess_ad_intent(intent, consents, budget, now=..., max_age_seconds=...)` validates a closed intent with opaque client/subject/account/campaign/revision/provider/jurisdiction/purpose, tuple assets/channels, positive exact-int minor units <=2**63-1, uppercase three-letter currency and exclusive expiry. The caller authenticates F16 Permission/Lifecycle/Review/AssetRight/ReplayReceipt snapshots outside this API; use the exact accepted dataclasses returned by `load_dependency('f16')`. Required tracking and audience_export channels receive separate Request/evaluate calls. Budget is explicitly synthetic binding evidence with its own expiry/revocation/account/campaign/revision/provider/currency/amount checks. Inspect consent and budget diagnostics independently; no positive combination authorizes execution.

SyntheticJournal.reserve accepts the actual F04 five-field identity and the complete closed advertising intent plus payload_ref, including amount/currency/channels/assets and all bindings. It fingerprints full intent, returns deep copies and rejects changed intent under the same key. record_prerecorded_unknown describes HELD->SUBMITTED->UNKNOWN history of an existing synthetic fixture; it submits nothing. Reconcile passes original bytes unchanged to a caller-trusted fixture verifier. Binding/freshness/original-byte/replay checks precede mutation. OCCURRED appends RECONCILED/CONFIRMED retaining reservation; NOT_OCCURRED appends a held tombstone without retry. Snapshot/restore validate F04 schemas, all transitions, closed shapes, deterministic receipt identity, chronology and replay index. Restored runtime remains HOLD while preserving historical receipt truth. No concurrency, durable storage, usable upstream backup or real reconciliation guarantee is claimed.
