# Security boundary

Pure offline diagnostics and in-memory synthetic history only. No provider transport/client/SDK/endpoint, network lookup, credentials, account creation, ads/spend, central adapter registration or persistent/native store. Public dependencies are pinned exact bytes with a closed lock and verified component-local loader; no vendored shared code, private execution instruction fallback, arbitrary plugin import, Git fetch/hooks/helpers/replacements/lazy fetch or network installation. Local Git store and exclusive destination parent are trusted caller-managed prerequisites; do not supply hostile repository configuration or concurrently mutate those paths.

F16 evidence classes are not authentication. A trusted caller must authenticate originals, current revocation/lifecycle/replay checkpoint/reviewer and rights authority. Channels are separate tracking/audience_export; unrelated consent never substitutes. Budget binding is synthetic test evidence, not financial authority. Explicit clock and exclusive expiry prevent hardcoded-time authorization. Exact integer amounts reject bool, floats, NaN/infinity and overflow; opaque bounded references and generic errors avoid echoing input secrets. Raw payloads, PII and token/payment values are excluded from fixtures and receipt state.

The journal verifier consumes original bytes, never a self-asserted proof flag. Replay events, full intent fingerprints and immutable receipt chains prevent changed-intent reuse and UNKNOWN blind retry in this synthetic model. Caller receives deep copies. Historical CONFIRMED receipts remain immutable while runtime/config/restore is HOLD. No durable concurrency, authenticated real-world truth, quota enforcement or real backup claim. Root independently inspects implementation and tests, exercises broken guards in disposable copies, validates dependency origins and scans all published source/history; authored tests are not execution evidence.

Actual native isolation, descendant cancellation, provider quota, runtime/legal/production qualification remain outside this source lease. No acceptance IDs are closed. External upstream release/security/SBOM/license/vulnerability evidence is unknown and assigned to provider/platform owners. Current native CI/protections and independently reviewed root authority remain required; model review alone cannot grant business effects.
